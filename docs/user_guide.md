# 百度网盘加密备份工具使用说明

本文面向普通 Windows 用户，目标是让不会编程的人也能按步骤完成安装、授权、备份、检查、清理和恢复。

> 当前项目仍处于 P3 阶段 14 打包发布与最终验收阶段。源码已经具备备份、百度授权、远端校对、原始数据清理和恢复等核心能力，也已经能构建 Windows onedir 发布目录；但干净 Windows 环境的完整安装、授权、备份、校对、清理、恢复、升级、卸载和敏感信息审计矩阵仍未全部完成。因此，在正式发布前，请把本文当作发布候选使用说明，不要把当前状态误认为最终稳定版。

## 1. 软件能做什么

本软件用于把 Windows 电脑上的文件和文件夹加密备份到百度网盘。

它会做这些事：

1. 让你选择要备份的文件或文件夹。
2. 生成加密 7-Zip 压缩包。
3. 把加密压缩包上传到百度网盘的应用目录。
4. 在本机 SQLite 数据库记录“哪个文件备份到了哪里”。
5. 通过云端服务同步索引，方便后续多设备校对和恢复。
6. 提供“来源映射”和“远端校对”页面，让你检查备份结果。
7. 只有在你手动确认后，才允许清理原始文件。
8. 支持从本地缓存或百度网盘远端压缩包恢复文件。

它不会做这些事：

1. 不会自动删除你的原始文件。
2. 不会默认永久删除任何原始数据。
3. 不会要求你把百度 access token 或 refresh token 粘贴到软件里。
4. 不会收集你的百度账号密码。
5. 不会在云端保存你的备份压缩包密码。
6. 不会在恢复时默认覆盖已有文件。

## 2. 使用前准备

### 2.1 你需要准备什么

请先确认你有：

1. 一台 Windows 电脑。
2. 一个可正常登录的百度网盘账号。
3. 一段你能长期记住或妥善保存的备份密码。
4. 一个有足够空间的本地缓存目录。
5. 稳定网络。

### 2.2 本地磁盘空间要求

建议你准备至少 40GiB 可用空间作为缓存。

缓存目录用于临时保存：

1. 扫描和压缩过程中的临时文件。
2. 加密后的 `.7z` 备份包。
3. 校验和恢复过程中的临时目录。
4. 百度上传断点续传状态。

不要把缓存目录放到一个快满的磁盘。缓存空间不足时，新备份任务可能无法开始。

### 2.3 密码一定要保存好

备份压缩包使用你输入的归档密码加密。

请务必做到：

1. 把密码保存在安全的位置。
2. 不要把密码写进仓库文件。
3. 不要把密码发到聊天工具或工单里。
4. 不要把密码放到公开网盘或共享文档里。

如果你丢失归档密码，已经上传到百度网盘的加密备份包将无法解密恢复。

### 2.4 百度账号安全说明

新增百度授权时，软件会打开百度官方授权页面或显示百度官方授权二维码。

请注意：

1. 百度账号密码只能在百度官方页面输入。
2. 软件界面不会要求你输入百度账号密码。
3. 软件只通过官方授权结果使用百度网盘 API。
4. 软件本机保存 Device Token 和密码派生参数时，Windows 默认使用当前用户 DPAPI 保护。

## 3. 获取和启动软件

### 3.1 普通用户使用发布目录

正式发布时，你应该拿到一个发布目录，例如：

```text
AutoBackupBDNetdisk/
```

目录里会包含主程序：

```text
AutoBackupBDNetdisk.exe
```

使用步骤：

1. 把整个 `AutoBackupBDNetdisk` 文件夹放到你希望保存软件的位置，例如 `D:\Apps\AutoBackupBDNetdisk`。
2. 打开这个文件夹。
3. 双击 `AutoBackupBDNetdisk.exe`。
4. 如果 Windows 弹出安全提示，确认来源可信后再允许运行。
5. 看到窗口标题“百度网盘加密备份”后，说明软件已启动。

不要只复制单独的 `.exe` 文件。发布目录里还有运行所需的依赖和数据库迁移文件，必须保持整个文件夹完整。

### 3.2 当前仓库开发阶段如何生成发布目录

这一节只给项目维护者或测试人员使用。普通用户正式使用时，应直接使用已经构建好的发布目录。

从仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\client_build.ps1
```

构建成功后，默认输出目录是：

```text
dist/client/AutoBackupBDNetdisk/
```

主程序是：

```text
dist/client/AutoBackupBDNetdisk/AutoBackupBDNetdisk.exe
```

如果只是想检查构建命令，不真正打包，可以执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\client_build.ps1 -DryRun
```

## 4. 首次启动后认识界面

主窗口左侧是导航栏，当前包含 6 个页面：

1. `备份任务`
2. `百度设置`
3. `来源映射`
4. `远端校对`
5. `原始数据清理`
6. `恢复`

窗口底部状态栏会显示当前操作结果或错误提示。

第一次使用建议按这个顺序操作：

1. 进入 `百度设置`，完成百度授权。
2. 回到 `备份任务`，创建备份任务。
3. 备份完成后进入 `来源映射` 查看备份记录。
4. 进入 `远端校对` 检查百度网盘远端对象。
5. 需要腾空间时，再进入 `原始数据清理`。
6. 需要找回文件时，进入 `恢复`。

## 5. 配置百度授权

### 5.1 打开百度设置页

1. 启动软件。
2. 点击左侧 `百度设置`。
3. 页面顶部会显示云端 API 地址、Device Token 状态和 Device ID。
4. Device Token 明文不会显示在界面里。

如果是第一次启动，软件会尝试注册当前设备并在本机保存 Device Token。

### 5.2 刷新账号列表

1. 在 `百度设置` 页面点击 `刷新账号`。
2. 如果你以前已经授权过百度账号，账号表中会出现可选账号。
3. 如果列表为空，说明还没有可用百度账号，需要新增授权。

### 5.3 新增百度授权

1. 在 `授权密码` 输入框中输入一段授权密码。
2. 点击 `生成扫码授权`。
3. 页面会显示授权状态、过期时间和二维码。
4. 用百度 App 扫描二维码，或点击 `打开授权页` 到百度官方页面授权。
5. 在百度官方页面确认授权。
6. 回到软件，点击 `检查并保存授权`。
7. 状态栏显示授权完成后，点击 `刷新账号`。
8. 在账号列表中确认新账号已经出现。

授权密码用途：

1. 用于本机派生 wrapping key，加密或解密百度 token。
2. 不等于百度账号密码。
3. 软件不会把它当作明文保存。
4. 后续校对、上传或远端恢复时，可能需要你再次输入同一授权密码。

### 5.4 选择百度账号

1. 在账号表中点击你要使用的百度账号。
2. 点击 `选择账号`。
3. 状态栏显示已选择账号后，后续备份和恢复会默认使用该账号。

### 5.5 验证解密

1. 在账号表中选择账号。
2. 在 `授权密码` 输入框中输入授权时使用的密码。
3. 点击 `验证解密`。
4. 如果提示 token 可解密，说明本机凭据材料和云端密文 token 可以配合使用。

如果验证失败，常见原因是：

1. 授权密码输错。
2. 当前 Windows 用户不是当时授权的用户。
3. 本机 DPAPI 凭据材料被删除。
4. 云端账号 token 已失效，需要重新授权。

## 6. 新建备份任务

### 6.1 进入备份任务页

1. 点击左侧 `备份任务`。
2. 页面上方是 `新建任务`。
3. 页面下方是 `任务列表`。

### 6.2 添加要备份的文件

方式一：选择文件。

1. 点击 `选择文件`。
2. 在弹出的窗口中选择一个或多个文件。
3. 点击打开。
4. 文件会出现在待备份来源表中。

方式二：选择文件夹。

1. 点击 `选择文件夹`。
2. 选择要备份的文件夹。
3. 点击确定。
4. 文件夹会出现在待备份来源表中。

方式三：拖拽。

1. 打开 Windows 文件资源管理器。
2. 找到要备份的文件或文件夹。
3. 拖到软件的 `备份任务` 页面。
4. 松开鼠标后，它会加入待备份来源表。

表格中会显示：

1. 类型：文件或文件夹。
2. 名称。
3. 路径指纹。

为了减少敏感路径泄露，界面默认显示路径指纹，不直接展示完整本地路径。

### 6.3 移除误选来源

如果选错了：

1. 在待备份来源表中点击那一行。
2. 点击 `移除来源`。

如果想全部重选：

1. 点击 `清空来源`。
2. 重新选择文件或文件夹。

### 6.4 填写任务名称

1. 在 `任务名称` 输入框中输入一个容易识别的名字，例如 `2026年6月桌面资料备份`。
2. 如果留空，软件会使用创建时间生成名称。

建议任务名写清楚备份内容和日期，方便以后恢复。

### 6.5 创建任务

1. 确认待备份来源无误。
2. 点击 `创建任务`。
3. 任务会出现在下方 `任务列表`。
4. 状态栏会显示任务已创建。

任务创建后，本地 SQLite 会记录任务和来源，并准备后续同步到云端索引。

### 6.6 开始、暂停、继续和取消

在 `任务列表` 中选中一个任务后，可以使用：

1. `开始`：输入归档密码和授权密码后，执行扫描、压缩、上传、同步和远端校对。
2. `暂停`：暂停处于运行状态但尚未进入后台执行的任务状态。
3. `继续`：对已暂停任务重新启动真实备份流程。
4. `取消`：取消排队、运行、暂停或可重试失败的任务状态。
5. `刷新`：重新读取任务列表。

点击 `开始` 前需要填写：

1. `归档密码`：用于加密本次 7-Zip 备份包，也是以后恢复文件时要输入的密码。
2. `授权密码`：用于本机解密百度授权 token；如果和归档密码相同，可以留空，软件会复用归档密码。
3. `执行前检查 40GiB 缓存预算`：普通用户建议保持勾选。

点击 `开始` 后，密码输入框会被清空。软件只在本次运行内存中使用这些密码，不会把密码写入数据库、日志或界面状态。

当前发布候选仍处于最终验收阶段。测试人员需要继续按发布验收矩阵确认干净 Windows 下真实授权、真实备份、校对、清理、恢复、升级和卸载。

## 7. 备份过程中会发生什么

完整备份流程大致如下：

1. 软件扫描你选择的文件和文件夹。
2. 记录不可读文件，但不会因为单个不可读文件中断整个任务。
3. 计算快速指纹。
4. 计算完整 MD5 和 SHA256。
5. 判断是否已经有相同内容。
6. 生成临时 manifest。
7. 使用 7-Zip AES-256 生成加密 `.7z` 备份包。
8. 校验加密备份包。
9. 删除临时明文 manifest。
10. 上传 `.7z`、`.meta.json` 和 `job.index.json` 到百度网盘。
11. 写入本地 SQLite 记录。
12. 通过云端 API 同步索引。
13. 调用百度列表接口校对远端对象。
14. 全部通过后，任务进入 completed 状态。

百度网盘远端目录按日期、设备和任务组织，大致形式是：

```text
/apps/{appname}/backups/{yyyy}/{MM}/{dd}/{device_id}/{job_id}/
```

备份包文件名中会包含 archive 序号和 SHA256，例如：

```text
000001-{archive_sha256}.7z
000001-{archive_sha256}.meta.json
```

## 8. 查看备份结果

### 8.1 使用来源映射页

1. 点击左侧 `来源映射`。
2. 如果知道任务 ID，可以填入 `任务 ID`。
3. 如果只记得文件名或部分关键字，可以填入 `关键字`。
4. 点击 `刷新`。

页面会展示本地数据库中记录的来源、文件、内容、归档和远端对象关系。

你可以重点看：

1. 任务是否存在。
2. 文件名是否符合预期。
3. 内容 hash 是否存在。
4. archive 信息是否存在。
5. 远端对象状态是否存在。
6. 清理状态和恢复状态是否符合预期。

界面为了保护隐私，默认尽量显示路径 hash 或摘要，不把完整敏感路径铺满界面。

### 8.2 使用远端校对页

远端校对用于检查本地记录和百度网盘实际对象是否一致。

操作步骤：

1. 点击左侧 `远端校对`。
2. 在 `范围类型` 中选择一种范围：
   - `job_id`：按备份任务校对。
   - `upload_session_id`：按上传会话校对。
   - `remote_dir`：按百度远端目录校对。
3. 在 `范围值` 中输入对应的 ID 或远端目录。
4. `账号 ID` 可以留空，默认使用当前设备已选择账号。
5. 在 `授权密码` 输入框中输入百度授权密码。
6. 默认勾选 `递归 listall`，表示递归读取远端目录。
7. 点击 `执行校对`。
8. 查看差异表和汇总信息。

差异状态可能包括远端缺失、大小不匹配、meta 缺失、fs_id 变化等。

### 8.3 修复校对结果

远端校对页默认只是检查，不会自动删除、覆盖或重传文件。

如果页面给出可审计修复候选，并且你确认要写入本地记录：

1. 先执行校对。
2. 仔细查看差异表。
3. 在 `确认短语` 输入框中输入页面提示的确认短语。
4. 点击 `确认修复`。
5. 等待状态栏提示修复写入结果。

不要在没看清差异时执行修复。校对修复会写入本地版本记录，并进入同步队列。

## 9. 清理原始数据

清理原始数据是危险操作。请只有在确认备份可用后再执行。

### 9.1 清理前必须明白的事

1. 软件不会自动清理原始文件。
2. 清理只能由你手动触发。
3. 默认方式是移入 Windows 回收站。
4. 永久删除是高级选项，默认隐藏。
5. 清理前软件会复查源文件是否还是备份时的那个文件。
6. 如果源文件大小、修改时间或 Windows 文件身份不一致，软件会禁止清理。

建议你在第一次使用时，不要立刻清理原始文件。先完成一次恢复演练，确认能恢复后再清理。

### 9.2 查看可清理候选

1. 点击左侧 `原始数据清理`。
2. 可以输入 `任务 ID` 缩小范围。
3. 可以输入 `关键字` 搜索任务名、文件名、relative path 或 content hash。
4. 点击 `刷新`。
5. 查看候选表。

候选必须满足备份完成、压缩包验证通过、远端对象已确认等条件。不是所有文件都会立刻成为可清理候选。

### 9.3 预演清理

预演不会真的移动或删除文件。

1. 在候选表中选中要清理的行。
2. 在 `方式` 中选择 `移入回收站`。
3. 在 `操作人` 中保留默认值或填写你的名字。
4. 在 `清理确认` 输入框中输入确认短语。
5. 点击 `预演`。
6. 查看结果。

如果预演失败，不要执行清理。请先阅读失败原因。

### 9.4 执行回收站清理

1. 在候选表中选中要清理的行。
2. `方式` 选择 `移入回收站`。
3. 确认这些文件已经完成备份和校对。
4. 在 `清理确认` 输入框中输入确认短语。
5. 点击 `执行清理`。
6. 等待状态栏显示清理结果。
7. 如需找回，可先到 Windows 回收站检查。

### 9.5 移动到隔离目录

如果不想放入回收站，也可以移动到隔离目录：

1. `方式` 选择 `移动到隔离目录`。
2. 在 `隔离目录` 中选择一个专门存放待确认文件的目录。
3. 选中候选行。
4. 输入清理确认短语。
5. 点击 `预演`。
6. 预演无误后点击 `执行清理`。

隔离目录建议放在空间充足、你能记住的位置。

### 9.6 永久删除

永久删除风险很高，普通用户不建议使用。

如果确实要永久删除：

1. 勾选 `高级选项`。
2. 选择永久删除方式。
3. 选中候选行。
4. 输入 `清理确认` 短语。
5. 输入 `永久删除确认` 短语。
6. 再次确认你已经做过恢复演练。
7. 点击 `执行清理`。

永久删除后，Windows 回收站通常无法找回。

## 10. 恢复文件

恢复用于把已备份内容从本地 archive 或百度网盘远端 archive 取回。

### 10.1 查看可恢复候选

1. 点击左侧 `恢复`。
2. 可以输入 `任务 ID`。
3. 可以输入 `关键字` 搜索任务名、文件名、relative path 或 content hash。
4. 点击 `刷新`。
5. 查看候选表。

候选表会显示：

1. 状态。
2. 任务名。
3. 文件名。
4. 大小。
5. SHA256 摘要。
6. 清理状态。
7. 恢复状态。
8. archive 摘要。
9. 阻塞原因。

### 10.2 选择恢复目标

在 `恢复目标` 区域选择：

1. `恢复到手动路径`：推荐普通用户使用。
2. `恢复到原路径`：只有你明确知道会恢复到哪里时再使用。

如果选择手动路径：

1. 点击 `选择`。
2. 选择一个空目录或专门的恢复目录。
3. 确认 `目标目录` 已填入。

建议先恢复到一个新建目录，例如：

```text
D:\恢复测试\2026-06-08\
```

确认文件无误后，再手动复制到正式位置。

### 10.3 选择冲突策略

当前支持：

1. `保留两者`：默认选项。目标位置已有同名文件时，恢复文件会自动追加后缀。
2. `跳过已有文件`：目标位置已有文件时不恢复该文件。

普通用户建议保留默认的 `保留两者`。这样不会覆盖现有文件。

### 10.4 输入归档密码

1. 在 `归档密码` 输入框中输入备份时使用的密码。
2. 这个密码只用于本次解压。
3. 软件不会把密码显示在界面中。
4. 密码错误时，恢复会失败，不会写入成功状态。

### 10.5 从本地 archive 恢复

如果本地缓存里的 archive 还在：

1. 选中要恢复的候选行。
2. 选择目标模式和目标目录。
3. 选择冲突策略。
4. 输入归档密码。
5. 点击 `执行恢复`。
6. 等待状态栏显示恢复结果。
7. 到目标目录检查文件。

恢复完成后，软件会重新计算 SHA256，并与 manifest 中记录的 hash 比对。只有一致才会标记为恢复成功。

### 10.6 从百度网盘远端拉取恢复

如果本地 archive 已被清理，但百度网盘远端对象仍存在，恢复页会需要远端拉取。

操作步骤：

1. 选中需要恢复的候选行。
2. 填好目标模式、目标目录、冲突策略和归档密码。
3. 在 `远端拉取` 区域，`账号 ID` 可以留空。
4. 在 `授权密码` 输入框中输入百度授权密码。
5. 点击 `执行恢复`。
6. 软件会通过云端读取密文 token，本机解密后调用百度下载接口。
7. 下载完成后继续执行 archive SHA256、7-Zip、manifest 和恢复后 SHA256 校验。

如果远端拉取失败，请检查：

1. 网络是否可用。
2. 百度账号授权是否仍有效。
3. 授权密码是否正确。
4. 百度网盘远端对象是否仍存在。
5. 本地缓存目录是否有足够空间。

## 11. 日常维护

### 11.1 定期查看来源映射

建议每次重要备份后：

1. 打开 `来源映射`。
2. 搜索任务或文件名。
3. 确认能看到对应记录。

### 11.2 定期做远端校对

建议定期：

1. 打开 `远端校对`。
2. 按 job_id 或远端目录执行校对。
3. 确认远端对象状态正常。

### 11.3 定期演练恢复

备份不是目的，能恢复才是目的。

建议你定期：

1. 选择一个小文件。
2. 恢复到临时目录。
3. 打开检查内容是否正确。
4. 确认恢复成功后删除临时恢复目录。

### 11.4 管理缓存空间

缓存空间不足时，新任务可能无法开始。

如果软件提示缓存不足：

1. 暂停创建新任务。
2. 确认已有任务是否完成。
3. 确认备份是否已经上传并校对。
4. 再按软件提供的缓存清理能力释放空间。
5. 不要手动删除未知 SQLite 文件或凭据文件。

## 12. 升级和卸载

### 12.1 升级

当前项目仍在发布候选阶段，正式安装器尚未完成。

如果你拿到新的 onedir 发布目录，建议：

1. 关闭正在运行的软件。
2. 备份旧的程序目录名称，例如改名为 `AutoBackupBDNetdisk_old`。
3. 解压或复制新的 `AutoBackupBDNetdisk` 目录。
4. 双击新版 `AutoBackupBDNetdisk.exe`。
5. 确认能打开主窗口。
6. 打开 `百度设置`，确认账号仍可读取。
7. 打开 `来源映射`，确认旧任务记录仍可查看。

不要删除用户数据目录和 Windows DPAPI 凭据材料，除非你明确要清空本机配置。

### 12.2 卸载

当前 onedir 发布目录可通过删除程序目录卸载程序本体。

卸载前请确认：

1. 没有正在运行的备份、清理或恢复任务。
2. 不再需要当前程序目录。
3. 已保存好归档密码。
4. 已确认本地数据、缓存和凭据是否需要保留。

删除程序目录只会删除程序文件。用户数据、SQLite、缓存和 DPAPI 凭据可能位于用户数据目录或你配置的缓存目录中。正式发布前，卸载清理边界仍需按发布验收矩阵继续确认。

## 13. 常见问题

### 13.1 软件打不开

请检查：

1. 是否双击的是 `AutoBackupBDNetdisk.exe`。
2. 是否保留了整个发布目录。
3. Windows 是否拦截了未知来源程序。
4. 杀毒软件是否误拦截。
5. 是否使用了当前系统支持的 Windows 版本。

如果你是测试人员，可以用源码方式或构建日志进一步排查。

### 13.2 百度账号列表为空

可能原因：

1. 尚未授权百度账号。
2. 云端 API 地址不可用。
3. 当前设备没有 Device Token。
4. 网络不可用。
5. 授权已过期或被撤销。

处理方式：

1. 点击 `刷新账号`。
2. 如果仍为空，重新执行 `生成扫码授权`。
3. 授权后点击 `检查并保存授权`。
4. 再次点击 `刷新账号`。

### 13.3 授权二维码过期

设备码授权有有效期。

处理方式：

1. 重新点击 `生成扫码授权`。
2. 使用新的二维码或授权链接。
3. 在有效期内完成授权。

### 13.4 验证解密失败

常见原因：

1. 授权密码输错。
2. 使用了不同 Windows 用户。
3. 本机凭据文件被清理。
4. 云端 token 已更新或失效。

处理方式：

1. 确认授权密码。
2. 切回当初授权的 Windows 用户。
3. 重新授权百度账号。

### 13.5 备份任务不能开始

常见原因：

1. 没有选择来源。
2. 缓存空间不足。
3. 百度账号未授权。
4. 授权密码无法解密 token。
5. 网络不可用。
6. 7-Zip 不可用或打包环境不完整。

处理方式：

1. 确认 `备份任务` 页面已有来源。
2. 确认磁盘至少有建议的缓存空间。
3. 到 `百度设置` 验证账号。
4. 稍后重试网络。

### 13.6 远端校对提示差异

先不要惊慌。差异可能来自：

1. 百度网盘远端文件被手动移动或删除。
2. 本地记录尚未同步完成。
3. 远端列表读取失败。
4. 上一次上传中断后仍待补偿。
5. 远端对象确实缺失或大小不匹配。

处理方式：

1. 重新执行一次校对。
2. 查看差异类型和建议。
3. 只在确认后输入确认短语并执行修复。
4. 不确定时先不要删除远端或本地记录。

### 13.7 清理候选为空

这通常是正常保护。

候选为空可能表示：

1. 任务还没有 completed。
2. archive 还没有通过验证。
3. 远端对象还没有确认。
4. meta 或 job.index 尚未上传。
5. 源文件身份变化。
6. 当前筛选条件太窄。

处理方式：

1. 清空 `任务 ID` 和 `关键字` 后点击 `刷新`。
2. 先执行来源映射和远端校对。
3. 确认任务真正完成后再回来查看。

### 13.8 恢复失败

常见原因：

1. 归档密码错误。
2. 本地 archive 已被删除。
3. 远端 archive 不存在。
4. 百度授权密码错误。
5. 目标目录没有写入权限。
6. 本地缓存空间不足。
7. 下载过程中网络断开。

处理方式：

1. 确认归档密码。
2. 若需要远端拉取，确认授权密码。
3. 换一个空的手动恢复目录。
4. 确认磁盘空间。
5. 重新执行恢复。

## 14. 安全注意事项

请长期遵守这些规则：

1. 不要把 `.env`、数据库、日志、token、密码、密钥文件发给别人。
2. 不要把百度账号密码输入到非百度官方页面。
3. 不要把归档密码和授权密码写入仓库。
4. 不要手动删除不认识的本地 SQLite 文件。
5. 不要在没恢复演练前清理重要原始文件。
6. 不要轻易使用永久删除。
7. 不要把“上传完成”当成“恢复一定可用”，必须做恢复演练。
8. 发现校对差异时，先检查再修复，不要直接删除远端对象。

## 15. 推荐的新手流程

第一次使用建议这样做：

1. 准备一个测试文件夹，里面放几个不重要的小文件。
2. 启动软件。
3. 到 `百度设置` 完成百度授权。
4. 到 `备份任务` 创建测试备份任务。
5. 等待备份完成。
6. 到 `来源映射` 搜索测试任务。
7. 到 `远端校对` 校对测试任务。
8. 到 `恢复` 把测试文件恢复到一个新目录。
9. 打开恢复出的文件确认内容正确。
10. 确认整个流程没问题后，再备份重要文件。
11. 重要文件备份后，至少做一次恢复演练。
12. 只有确认恢复可用后，再考虑使用 `原始数据清理`。
