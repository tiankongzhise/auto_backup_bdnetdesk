# PRD：百度网盘加密备份工具 v1.3

## 产品目标

本产品面向普通 Windows 用户，提供一个能把本机文件和文件夹安全备份到百度网盘的桌面工具。用户不需要理解 SQLite、PostgreSQL、revision、fs_id、uploadid 等工程概念，也不需要手工管理百度 token。

产品必须做到：

- 选择一个或多个本机文件/文件夹。
- 使用用户提供的归档密码生成 7-Zip AES-256 加密归档。
- 通过百度官方开放平台上传到 `/apps/{appname}/backups/...`。
- 在本地 SQLite 记录任务、来源、归档、远端对象、清理和恢复状态。
- 通过真实云端 API 异步同步索引到 PostgreSQL。
- 支持断点续传、远端校对、原始数据清理和来源级恢复。
- 不泄露用户密码、百度 token、Device Token、明文 manifest 或完整敏感路径。

## 用户与场景

| 用户 | 主要诉求 | 产品响应 |
| --- | --- | --- |
| 普通 Windows 用户 | 备份个人文件，出错时知道下一步做什么。 | 工作台给出当前状态、下一步动作和风险提示。 |
| 多设备用户 | 同一百度账号下多台电脑可查询和恢复自己的备份。 | 稳定 `device_id`、设备级历史拉取、云端索引同步。 |
| 测试/发布人员 | 确认发布包在干净 Windows 上真实可用。 | P3-14 R04-R14 发布验收矩阵。 |
| 维护开发者 | 能基于文档判断边界，不再靠猜。 | PRD/Design/Tech/Spec/Agents 分层文档。 |

## 支持范围

v1.3 支持：

- Windows 桌面客户端，使用 pywebview + WebView2 + 原生静态 HTML/CSS/JS。
- 批量选择文件和文件夹；备份页对用户表现为统一添加来源入口。
- 用户设置缓存目录、缓存额度和上传参数。
- 用户运行时输入归档密码和百度授权密码；密码不持久化。
- 百度设备码/授权码授权；百度账号密码只在百度官方页面输入。
- 客户端本地解密云端保存的密文百度 token，并直接调用百度网盘 API。
- 按用户选择源独立生成 archive；同一 job 汇总生成 `job.index.json`。
- 内容级去重；最终去重只使用完整 SHA256 和文件大小。
- 断点续传、远端对象校对、人工修复入口。
- 原始数据手动清理，默认移入 Windows 回收站。
- 来源级恢复；默认冲突策略为保留两者。
- 本地 SQLite 与云端 PostgreSQL 通过 Cloud Sync API 最终一致。

v1.3 不支持：

- 自动定时备份。
- 非 Windows 桌面发布。
- 非百度网盘存储后端。
- 客户端直连 PostgreSQL。
- 服务端解密百度 token 或保存用户明文密码。
- 默认永久删除原始数据。
- 恢复时默认覆盖已有文件。
- 用户手动填写百度 access token 或 refresh token。
- 把清理、删除或覆盖作为自动修复动作。

## 核心用户流程

### 首次启动与授权

1. 客户端启动后生成或读取稳定 `device_id`。
2. 如没有 Device Token，客户端调用真实云端注册设备并用 DPAPI 保存凭据。
3. 用户进入百度授权页，创建设备码或授权码会话。
4. 用户在百度官方页面完成授权。
5. 用户输入本项目授权密码，客户端派生 wrapping key，云端完成 token 加密入库。
6. 用户选择当前设备使用的百度账号。
7. 用户可执行授权密码验证，确认本机能解密云端密文 token。

验收口径：不得在本项目 UI 中收集百度账号密码；不得显示或保存百度 token、wrapping key、Device Token。

### 新建备份

1. 用户添加文件/文件夹来源。
2. 用户填写任务名，确认缓存目录、缓存额度和上传参数。
3. 用户点击开始，输入归档密码和授权密码。
4. 客户端执行扫描、指纹、去重、归档、标准验证、百度上传、Cloud Sync 和远端校对。
5. 任务完成后，工作台和备份页显示 completed、同步状态和可恢复/可清理入口。

验收口径：本地 SQLite 落盘成功后任务可继续；云端暂时不可用不能导致本地任务被误标记完成云同步。

### 继续任务

1. 用户看到 paused、running、failed_retryable 或云端历史导入的可继续任务。
2. 用户点击继续并重新输入运行时密码。
3. 客户端复用已完成的扫描、哈希、归档、上传账本或远端对象状态。
4. 无法继续时，UI 必须显示最后阶段和脱敏原因。

验收口径：不能因为本机没有后台 worker 就把云端导入的 running 任务变成不可操作死状态。

### 校对与同步

1. 用户打开校对与同步页。
2. 页面默认拉取本机设备历史。
3. 用户可查看来源映射、远端校对差异和 Cloud Sync summary。
4. 修复必须由用户显式选择和确认。

验收口径：真实云端同步必须通过 summary 回读匹配证明，不能只看本地 outbox `synced`。

### 原始数据清理

1. 清理页只展示满足清理门槛的来源。
2. 用户选择候选和清理方式。
3. 默认移入 Windows 回收站；永久删除隐藏在高级选项并需要确认短语。
4. 清理前复查源文件身份，变化则禁止清理。

验收口径：清理只由用户触发，不能自动触发；清理失败要写记录，不能静默忽略。

### 恢复

1. 用户按任务、来源、日期或关键字选择来源级恢复候选。
2. 用户选择手动目录或原路径，输入归档密码。
3. 本地 archive 可用时直接恢复；缺失但远端确认时，要求授权密码并从百度拉取。
4. 解压后按 manifest 恢复所选来源范围，恢复后重新计算 SHA256。

验收口径：恢复候选以用户当初选择的来源为粒度，不暴露文件夹内部单文件恢复作为主流程；覆盖恢复默认关闭。

## 功能边界

### 远端路径

百度远端目录固定为：

```text
/apps/{appname}/backups/{yyyy}/{MM}/{dd}/{device_id}/{job_id}/
```

archive 文件放在该 job 目录下的 `archives/` 子目录。文件名包含 `archive_seq` 和 `archive_sha256`。不得再使用 `archive_sha256` 作为远端目录分桶。

### 去重

快速指纹只用于候选筛选，最终重复判断只能使用：

```text
size + file_sha256
```

内容指纹不得混入路径、名称、时间、设备或任务信息。

### 密码与凭据

- 归档密码只在运行时进入 7-Zip 调用，不写数据库、日志、前端状态或远端元数据。
- 授权密码只用于本机派生 wrapping key，不保存明文。
- Device Token 使用 DPAPI 或运行时环境提供；不得提交或输出。
- 百度 access token / refresh token 只以云端密文 envelope 和本机内存解密结果存在。
- KDF salt 和参数可持久化，但不得保存授权密码或 wrapping key。

### 清理与恢复

- 清理只处理原始来源文件，不删除百度远端对象作为默认行为。
- 恢复默认保留两者，覆盖恢复如后续实现，必须先加入覆盖前回收站保护和单独验收。

## 产品验收

v1.3 发布前必须通过：

- 源码/开发机自动化：客户端定向测试、全量 pytest、compileall、Go 测试、发布 dry-run。
- 真实联调：百度授权、真实百度上传、Cloud Sync summary 回读、远端校对、真实清理测试文件。
- 干净 Windows R04-R14：首次启动、授权、备份、校对、清理、恢复、断网补偿、升级、卸载、敏感信息审计。

本次文档审计确认：当前代码已覆盖大部分核心能力，但完整发布仍以干净 Windows R04-R14 通过为准。
